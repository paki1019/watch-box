    전체 복사

    시계 삭제

    가져오기

    1. AI(ChatGPT·Claude·Gemini 등)에 시계 이름을 적고, 그 아래에 복사한 프롬프트 붙여넣기
    2. AI가 출력한 JSON을 아래에 붙여넣기

      사용 방법

      시계 추가

      1. 가져오기 → 프롬프트 복사 → 보유·드림 중 선택
      2. 웹 검색이 되는 AI(ChatGPT·Claude·Gemini 등)에 시계 이름을 먼저 적고, 그 아래에 프롬프트를 붙여넣어 보내기
      3. 출력된 JSON을 가져오기 창에 붙여넣고, 목록과 이미지를 확인한 뒤 저장

      보기와 고치기

      • 위쪽 탭에서 보유와 드림 목록을 오갑니다
      • 카드를 누르면 정보 창이 열립니다. 고친 뒤 저장, 지우려면 삭제
      • 위쪽의 시계 · 합계 · 브랜드를 누르면 선호도·가격대·브랜드로 걸러 볼 수 있습니다
      • 판 시계는 판매 정보를 적으면, 드림 시계는 목록에서 숨기기를 바꾸면 목록에서 빠집니다

      저장과 백업

      • 시계 정보는 크롬 계정으로 동기화되어 다른 기기에서도 보입니다. 이미지는 기기마다 주소로 받아 옵니다
      • 가져오기 창의 맨 위 제목을 누르면 전체 시계가 JSON으로 복사됩니다. 보관해 두었다가 가져오기 창에 붙여넣으면 복원됩니다

      더 자세한 사용법

      • 도움말 프롬프트 복사를 눌러 AI에 붙여넣으면 이미지 고르기, 숨기기, 동기화, GitHub 스토리지, 업데이트까지 자세한 사용법을 물어볼 수 있습니다
      • 원하는 기능이 없거나 오류가 있으면 GitHub Issues에 남기거나 paki1019@gmail.com로 보내 주세요

      동기화 설정

      기본은 크롬 계정 동기화입니다. 설정이 필요 없지만 용량이 약 100KB로 제한되고, 이미지는 주소만 동기화됩니다.

      GitHub 스토리지(고급)를 연결하면 시계 정보와 이미지 사본을 내 비공개 저장소에 보관합니다. 용량 제한이 사실상 없고, 이미지 주소가 죽어도 사본으로 볼 수 있습니다. GitHub 계정과 비공개 저장소, 토큰이 필요합니다.

      Watch Box 시작하기

      보유 시계와 드림 워치(갖고 싶은 시계)를 정리하는 프로그램입니다. 아직 등록된 시계가 없습니다.

      1. 가져오기 → 프롬프트 복사 → 보유·드림 중 선택
      2. AI(ChatGPT·Claude·Gemini 등)에 시계 이름을 적고, 그 아래에 프롬프트를 붙여넣어 보내기
      3. 출력된 JSON을 가져오기 창에 붙여넣고 저장

      다른 기기에서 쓰던 시계는 같은 크롬 계정으로 로그인하면 잠시 뒤 자동으로 나타납니다.
